**Goal:** Set up the free accounts, tools, security, and workspace you will use throughout the course,
and make a realistic plan for working through power and data challenges.

## Learning Objectives

By the end of this setup you can:

- Create the core free accounts a VA needs and keep them secure
- Explain what a password manager and two-factor authentication are, and why a VA must use them
- Set up a simple, tidy folder and task system to run client work
- Make a plan for power and data so you can deliver reliably

## 1. The tools a VA uses (and free options)

You do not need paid tools to start. Here is what each type is for and a well-known free option. Tools
and free tiers change, so **check the current details on each tool's own website** before you rely on it.

| Need | What it is for | A common free option |
|---|---|---|
| Email and documents | Your professional email, docs, sheets | Google Workspace (free Gmail) or Microsoft 365 (free Outlook) |
| Password manager | Store and share passwords safely | A reputable password manager (check current free tiers) |
| Task board | Track tasks for each client | Trello, Notion, or ClickUp (free tiers) |
| Scheduling | Let clients book time without email tag | A calendar booking tool with a free tier |
| Video calls | Client calls and interviews | Google Meet or Zoom (free tier) |
| Time tracking | Record hours per client and task | A free time tracker, or the CSV in this course |
| File storage | Keep client files organised | Google Drive or OneDrive (free tier) |

> **Note:** Do not sign up for ten tools today. Create an email, a password manager, and one task board
> now. Add the others in the week you first need them.

## 2. Create your professional email

A client will not take "coolguy2000@..." seriously. Make a clean, professional address.

- Good: firstname.lastname@... or firstnamevirtualassistant@...
- Use it only for work, so your inbox stays focused
- Add a simple signature: your name, "Virtual Assistant", and how to reach you

## 3. Security first (this is not optional for a VA)

Clients trust you with access to their business. Protecting that is part of the job.

- **Password manager:** a tool that creates and stores strong, unique passwords so you never reuse one.
  You remember one master password; it remembers the rest.
- **Two-factor authentication (2FA):** a second step at login (a code on your phone) so a stolen
  password alone cannot get in. Turn it on for your email and every important account.

> **Privacy:** Never store client passwords in a notebook, a chat message, or a plain document. Use the
> password manager. When a client needs to give you access, use the tool's own "share" or "invite"
> feature instead of sending a password. You will practise this in Week 7.

## 4. Set up a tidy workspace

- A **main folder** with one sub-folder per client
- A **task board** with one list or board per client
- A **time-tracking** habit from day one (download the [time-tracking sheet](/downloads/virtual-assistant/time-tracking.csv) and open it in any spreadsheet app)

A tidy system is itself a skill clients pay for. If your own files are a mess, theirs will be too.

## 5. Plan for power and data

Remote work in Nigeria means planning around power and data. Decide your plan now:

- **Power:** where will you charge your laptop and phone? A power bank, a nearby spot with power, or set
  work hours around supply. Save your work often.
- **Data:** keep a data buffer for the end of the month. Learn which tasks you can do offline (writing,
  formatting) and do them when data is low.
- **Backup:** know a second place you can work from if power or data fails on a client deadline.

> **Tip:** Tell clients your working hours, not your power situation. "I work 9am to 3pm your time" is
> professional. Deliver inside the hours you promise, and communicate early if something will be late.

## 6. Setup checklist

- [ ] Professional email created, with a signature
- [ ] Password manager set up
- [ ] Two-factor authentication on for email and key accounts
- [ ] One task board created
- [ ] Main folder + first client sub-folder created
- [ ] Time-tracking sheet saved and opened
- [ ] A written power-and-data plan

> **Important:** You will reuse this setup for every client and every other InnovaTech course. Doing it
> properly once saves you hours later.

## Self-Check Questions

1. Why must a VA use a password manager and 2FA, rather than just remembering passwords?
2. What is the safe way for a client to give you access to an account?
3. What is one task you can do offline when your data is low?
