**Goal:** Start a client relationship cleanly, build the check-in habits that lead to retainers, plan beyond
your first client, and graduate with a complete career package. You'll assemble and rehearse the real thing,
not read about it.

## What you'll be able to do

- Onboard a first client cleanly
- Send proactive, professional check-in messages
- Build communication habits that lead to retainers
- Diversify beyond one client and set a 90-day plan
- Assemble and present your complete VA Career Package

## Before you start (about 10 minutes)

- Open the [onboarding checklist](/downloads/virtual-assistant/client-onboarding-checklist.md) and the
  [career package checklist](/downloads/virtual-assistant/va-career-package-checklist.md).
- Warm-up: imagine you just signed your first client. Write the first three questions you'd ask them in week
  one. You'll fold these into your onboarding checklist below.

## Try it 1 - Build your onboarding checklist

**Why it matters:** a clean first week sets the tone; clear access, expectations, and a first deliverable
build trust fast.

**Do this now - using the onboarding checklist:**
1. List the access you'd set up the safe way (no shared passwords in plain text).
2. Write the communication expectations you'd agree, and name the first deliverable.
3. Add the clarifying questions you'd ask early instead of guessing.

**You've got it when:** you have a personal onboarding checklist you could run on day one.

## Try it 2 - Write check-in messages that keep clients

**Why it matters:** predictable, results-led updates mean a client rarely has to chase you, which is exactly
why they keep you.

**Do this now - using the [check-in examples](/downloads/virtual-assistant/client-check-in-message-examples.md),
draft four short messages:**
1. A start-of-week plan.
2. A mid-week update.
3. An end-of-week summary.
4. An "I noticed a problem" message, flag early, with a suggested fix.

**You've got it when:** you have four ready check-in messages in your own voice.

## Try it 3 - Plan a sustainable career

**Why it matters:** depending on one client is risky; a plan for 2 to 3 clients and rising rates is how this
becomes a real income.

**Do this now:**
1. Note how you'll over-communicate in the first month to build trust.
2. Pick the gentle script you'll use to ask for feedback and a testimonial.
3. Set a **90-day goal** using the [template](/downloads/virtual-assistant/ninety-day-goal-template.md):
   clients, income, and the skills you'll keep learning (other InnovaTech courses help here).

**You've got it when:** you have a specific, realistic 90-day client and income goal written down.

## Try it 4 - Assemble your career package

**Why it matters:** one organised package is what you show every future client, and your proof you're
job-ready.

**Do this now - gather everything using the career package checklist:**
1. Niche statement (Week 1) and three live profiles (Week 2).
2. Portfolio and rate sheet (Week 4).
3. Full Application Tracker log (Weeks 3 to 6).
4. Either a signed client/job or a documented next-steps plan (your 90-day goal).

**You've got it when:** all five pieces sit in one place, polished and ready to share.

### Watch out for

- Shared logins in plain text during onboarding, set up access the safe way
- Going quiet after you start, over-communicate early instead
- Depending on a single client, line up 2 to 3
- Measuring success only as "signed on day 49", momentum and a full pipeline count

## This week's job-hunt focus

**Close out.** Either **confirm a first client/job**, or leave with a **fully active pipeline** and a
**concrete next-2-weeks plan**. Success is measured by momentum, not a guaranteed job on day 49.

### Grading guide

| Criteria | Weight |
|---|---|
| Complete, polished career package | 40% |
| Onboarding checklist + check-in habits ready | 20% |
| 90-day plan is specific and realistic | 20% |
| Final outcome: signed client/job OR a clear dated plan | 20% |

### Definition of done

- [ ] All five career-package items assembled
- [ ] Onboarding checklist and check-in examples ready to use
- [ ] 90-day goal set
- [ ] A confirmed client/interview or a dated next-2-weeks plan

## Can you do these now?

1. What must be agreed in writing before you start work for a client?
2. What proactive check-ins keep a client happy, and how often?
3. Why diversify beyond one client, and how will you start?
4. What does "success is measured by momentum" mean for your graduation?

## Facilitator Notes

**Prepare:** the certificate template (blue and white branded, **do not use gold**), a simple graduation
venue (a cafe or office is fine), optional introduction/referral contacts, and a final mock-interview slot
if a learner needs it. Make graduation a genuine milestone: recap each learner's progress, present the
certificate personally, and set them up with momentum, an active pipeline and a 90-day plan. For learners
without a client yet, keep outcomes honest and encouraging: a complete package plus consistent applying is
success. Reinforce diversifying beyond one client and continued learning.
