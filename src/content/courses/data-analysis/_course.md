## 3. How Each Week Works

1. **Before the mentoring session:** watch the videos, read the lesson, and try the practice exercises.
2. **In-person mentoring (90 min):** review, live problem-solving, and the facilitator checks your work. See the *Mentoring Session Plan* in each week's file.
3. **After the session:** finish and submit the weekly assignment **before the next session**.
4. **Daily habit:** 30–60 minutes of practice every day beats one 6-hour cram session.

> **Rule of thumb:** If you are stuck for more than 30 minutes, write down exactly what you tried and send it to the facilitator on WhatsApp. Describing your problem clearly is itself a core analyst skill.

## 6. Practice Dataset: "NaijaMart"

All weeks use the same fictional retail business so that skills build on each other. Files are in `datasets/`:

| File | Rows | Purpose |
|---|---|---|
| `orders_raw.csv` | ~2,025 | **Messy** data for cleaning practice (Weeks 2, 9, 10) |
| `orders_clean.csv` | 2,000 | Clean data for analysis (Weeks 3–11) |
| `customers.csv` | 200 | Customer details (joins) |
| `products.csv` | 15 | Product catalogue (joins) |
| `generate_data.py` | - | Regenerates the files. Change `random.seed(42)` to create a new version for each student. |
