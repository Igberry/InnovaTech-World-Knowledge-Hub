**Goal:** Run one complete analysis from business question to recommendation, publish a clean portfolio, and take concrete steps toward remote work. This week is about doing and shipping, not reading - you build the things that help you get hired.

## What you'll be able to do
- Run a full analysis from question to recommendation
- Present findings clearly to a non-technical audience
- Build a GitHub portfolio and a data-analyst LinkedIn profile
- Write proposals and prepare for interviews and technical tests

## Before you start (about 10 minutes)
- Agree your capstone option with the facilitator (ideally back in Week 11 so you have time).
- Open your `data-analysis-portfolio` repo and list what is already in it.
- Warm-up: write, in one sentence, the business question your capstone will answer.

## Try it 1 - Run the capstone end to end

**Why it matters:** this single project shows an employer the whole skill set working together.

**Do this now:**
1. Pick one option: **A** real local data (a shop, school, church, or NGO, with permission, anonymised), **B** a new public Kaggle dataset, or **C** a business case on NaijaMart with a fresh angle (for example "how to reduce returns and grow repeat purchases").
2. Write a clear problem statement and 3 to 5 specific questions.
3. Work the pipeline you now own: clean (Excel, SQL, Python, or Power Query), query (5+ SQL queries), analyse in Python, and build a dashboard.
4. End with specific, measurable recommendations tied to your evidence.

**You've got it when:** your numbers reconcile across tools and every chart has an insight title.

Structure it as a case study: business problem, data (source, size, limits, privacy), approach, cleaning, analysis and findings, recommendations, limitations and next steps.

> Privacy: never publish real customer names, phone numbers, or financial details. Get written permission to use a real business's data.

## Try it 2 - Organise the portfolio repo

**Why it matters:** a tidy repo is the first thing a recruiter judges.

**Do this now, set up this structure:**
```
data-analysis-portfolio/
  README.md                     <- intro + links to all projects
  01-excel-sales-dashboard/     <- README + dashboard.xlsx
  02-sql-business-questions/    <- README + queries.sql
  03-python-eda/                <- README + analysis.ipynb
  04-powerbi-executive-dashboard/ <- README + dashboard.pbix + dashboard.pdf
  05-capstone/                  <- README + files
```
Each project README needs: title, problem, tools, key findings (with numbers), screenshots, and how to run it.

**You've got it when:** a stranger can open your repo and understand all five projects in two minutes.

## Try it 3 - Write a main README that sells you

**Why it matters:** your repo homepage is your pitch.

**Do this now:**
1. Open with one line: "Data analyst skilled in Excel, SQL, Python and Power BI, helping businesses turn data into decisions."
2. List your skills.
3. Link the five projects, each with a one-sentence result.
4. Add contact and LinkedIn.

**You've got it when:** the top of your README states who you help and shows proof.

## Try it 4 - Build the LinkedIn and freelance profiles

**Why it matters:** this is where the opportunities actually come from.

**Do this now:**
1. Pick a target niche (retail/e-commerce, education, NGOs/health, finance, marketing analytics).
2. Write a specific headline, for example: "Entry-level data analyst | Excel, SQL, Python, Power BI | I build dashboards that show retail businesses where they lose money."
3. Fill the About (who you help, tools, a result, a call to action), pin your GitHub and best dashboard under Featured, add all five projects, and list your skills.
4. Set up at least one freelance profile (Upwork or similar) with the same positioning.

**You've got it when:** your LinkedIn and one freelance profile are live and specific, not generic.

## Try it 5 - Send real proposals and prepare for interviews

**Why it matters:** applications are a skill you practise, not a lottery you wait on. This course builds job-ready skills; the work of applying is yours to do consistently.

**Do this now:**
1. Use this proposal template on 5 real posts, logged in a tracker:
```
Hi [Name],
I read your post about [their problem, e.g. messy sales reports].
I'd help by [specific approach: clean the data in Excel/SQL, build a dashboard that shows X and Y].
Here's a similar project I built: [link]. It [result].
I can deliver [specific deliverable] in [timeframe]. Could we do a 15-minute call?
Best, [Name]
```
2. Prepare STAR answers (Situation, Task, Action, Result) for the common questions: walk me through a project; how do you handle messy data; how would you check a number is wrong; explain a LEFT JOIN simply; tell me about a surprising finding.
3. Revise the technical topics: Excel lookups and pivots, SQL joins and windows, pandas basics, Power BI DAX and modelling, stats basics.

**You've got it when:** you have sent 5 real, specific proposals and can answer the common questions using STAR.

> Be careful with scams. Never pay to get a job. Be suspicious of cheque payments, "training fees", requests for equipment money, or offers that skip any interview. Check the company's website and reviews.

Where to look: freelance (Upwork, Fiverr, Freelancer), remote jobs (LinkedIn Jobs, We Work Remotely, Remote OK, Remotive), local (banks, telecoms, oil and gas services, NGOs, company career pages, facilitator referrals), and practice (Kaggle).

### Capstone checklist

- [ ] Question defined before analysis starts
- [ ] Raw data preserved; cleaning documented
- [ ] Numbers reconcile across tools
- [ ] Every chart has an insight title
- [ ] Recommendations are actionable
- [ ] README explains how to reproduce the work
- [ ] Spell-checked, with no private data exposed

### Presentation scoring rubric

| Criterion | Points |
|---|---|
| Clear problem and audience | 15 |
| Quality of analysis and accuracy | 25 |
| Visuals and clarity | 20 |
| Actionable recommendations | 20 |
| Delivery and handling questions | 20 |

| Time | Activity |

| 10-60 min | Capstone presentations: 15 min each plus 10 min Q&A (facilitator acts as client) |
| 60-85 min | Mock interview, one student at a time, with scored feedback |
| 85-100 min | Portfolio and LinkedIn review (screen share); final fixes |

| 110-120 min | Certificate presentation, photos, and testimonials |

## Facilitator Notes

Guard against over-promising: the course builds job-ready skills and a real portfolio, but outcomes depend on each student's follow-through, so frame careers honestly and never guarantee a job or income. Act as a demanding but fair "client" in the capstone Q&A; pushing students to defend their recommendations is the single best interview prep. Insist on reconciliation across tools in the capstone - it is the fastest way to catch mistakes and a strong talking point. Review LinkedIn and freelance profiles live; generic headlines are the most common weakness, so push for a specific niche. Keep the scam warnings prominent, especially for students new to remote work. The 30-day plan matters: students who leave with a concrete weekly application target follow through far more often.
