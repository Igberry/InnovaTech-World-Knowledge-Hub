**Goal:** In about two hours you'll pick the right account, switch on strong sign-in, and build a clean practice workspace. Little reading, mostly clicking - you set it up by doing it.

## What you'll have when you finish

- An account you fully control, with a second sign-in step switched on
- A tidy Drive folder from the template, named the way pros name files
- A safe habit for sharing: start Restricted, add only who needs it
- Offline access tested on one file, so a bad connection never stops you

## Before you start (about 10 minutes)

- Grab a laptop with a keyboard if you can. Most of this course is arranging rows, editing slides and checking sharing, which is painful on a phone.
- Open Chrome or Edge and make sure you can sign in to the Google Account you'll use.
- Quick decision: is this account personal, or managed by a school or employer? A managed account can block sharing, Forms, Sites or security changes. If it is managed, ask the administrator before changing any policy.

## Try it 1 - Lock down your account

**Why it matters:** this account will hold all your practice work. Two minutes now saves a stolen account later.

**Do this now:**
1. Open [Google Account security](https://myaccount.google.com/security).
2. Turn on **2-Step Verification** (follow the prompts for a passkey, phone code or security key you can recover).
3. Check your recovery email and phone are current and ones you control.
4. Read the official [2-Step Verification guide](https://support.google.com/accounts/answer/185839) only if a step is unclear.

**You've got it when:** signing in asks for a second step, and you can name your recovery method.

> **Never share a password, one-time code or recovery code** with a mentor, caller or message - no one helping with this course needs them.

## Try it 2 - Build your course workspace

**Why it matters:** a predictable folder now means you never lose a file for the next five weeks.

**Do this now:**
1. Download the [folder structure template](/downloads/google-workspace/workspace-folder-structure-template.md) and rebuild it inside **your own Drive**.
2. Save one working copy of each download; keep starter files separate from finished work.
3. Name a test file the pro way: `2026-11-13_FreshBites_WeeklyReport_v01`. Short, dated, sorts itself.
4. Grab the [shortcuts cheat sheet](/downloads/google-workspace/productivity-shortcuts-cheat-sheet.md) and try three keyboard shortcuts right away.

**You've got it when:** your Drive has a dated, clearly named folder and you can find any file at a glance.

> Never put a real customer, student or colleague name - or any real private data - in a practice file. Fresh Bites is fictional; keep it that way.

## Try it 3 - Practise safe sharing

**Why it matters:** "Anyone with the link" is the single most common way files leak. Train the safe habit once.

**Do this now:**
1. Open any practice file and open its Share panel.
2. Set it to **Restricted**, then notice the difference between Viewer, Commenter and Editor.
3. If you have a second account you control, add it as Viewer, open the file from there to test, then remove the access.

**You've got it when:** you can explain, in one line, why Restricted plus the least role beats "Anyone with the link".

## Try it 4 - Test offline before you need it

**Why it matters:** power and data cut out. A file you set up offline keeps working; one you didn't, doesn't.

**Do this now:**
1. In Chrome or Edge (a normal, non-private window), follow Google's [offline setup](https://support.google.com/docs/answer/6388102) to switch on offline access in Drive.
2. Make one unimportant file available offline and open it.
3. Check [your storage](https://drive.google.com/settings/storage) so you know how much room you have before uploading anything large.

**You've got it when:** one test file opens offline, and you know your storage is shared across Gmail, Drive and Photos.

### Watch out for

- Treating cloud sync as a backup - a deletion or bad edit syncs too. Keep a second copy of anything important.
- Saving your password on a shared or borrowed device.
- Installing a "configuration profile" or granting device-wide access just because a page asks.
- Switching to a paid plan just to finish a course task - you never need to.

## You're ready when

- [ ] You can sign in and reach Gmail, Drive and Docs.
- [ ] You know whether the account is personal or managed.
- [ ] A second sign-in step is on, and recovery options are set.
- [ ] The folder and shortcut templates are downloaded and open.
- [ ] You know where downloads and local copies are saved.
- [ ] You checked storage and tested one offline file.
- [ ] No real customer, student, financial or private data is in the practice folder.
- [ ] You can point to the **Restricted**, Viewer, Commenter and Editor choices.

If a feature is blocked, note the account type and error (without private details) and use the labelled alternative in each lesson.
