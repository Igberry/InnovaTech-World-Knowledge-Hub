# Mock Client Workspace Brief (Session C Practice)

> Use this in the Week 2 Hands-On Tools Practice Lab. You will set up a realistic workspace for a
> **fictional** client, as if you just got hired. All details are made up; use no real client data.

## Your fictional client

- **Name:** Ada Okoro, founder of "BrightLeaf Coaching" (fictional)
- **What she does:** life and career coaching for young professionals
- **Her problem:** her inbox, calendar, and files are chaotic; she loses track of bookings
- **What she hired you for:** inbox and calendar management, plus tidy file organisation

## Set up the workspace (practise live)

- [ ] **Google Drive:** create a client folder `01-Clients/BrightLeaf-Coaching/` with sub-folders
      (Admin, Content, Finance, Reference)
- [ ] **Google Calendar:** create a shared calendar; add three sample bookings across a week (no clashes)
- [ ] **Gmail:** set up two labels (e.g., "Action needed", "Bookings") and one filter
- [ ] **Task board (Trello/Notion):** create a board with columns To do / Doing / Waiting / Done, and add
      five sample tasks
- [ ] **Slack (or chat tool):** set a professional display name and write one sample status update
- [ ] **Time tracker:** start a project for BrightLeaf and log one sample entry

## Finish

- [ ] Write a two-line "here's how your workspace is organised" note you would send Ada
- [ ] Note anything you found tricky to raise with your mentor

> **Privacy:** This is fictional practice. When you have a real client, set access through each tool's own
> share/invite feature, never by having the client email you a password.
