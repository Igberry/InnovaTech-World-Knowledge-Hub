# Proposal Scoring Checklist (10 Points)

> Score any proposal against this before sending (and use it in your Session C review). Aim for 8+.
> One point each.

| # | Check | Point |
|---|---|---|
| 1 | The first line mirrors the client's specific need (not generic) | [ ] |
| 2 | It leads with the client, not with "I am a hardworking VA" | [ ] |
| 3 | There is one line of real proof (sample, result, or transferable skill) | [ ] |
| 4 | It includes one concrete thing you'd actually do for them | [ ] |
| 5 | Availability and rate are stated clearly | [ ] |
| 6 | There is one easy call to action | [ ] |
| 7 | It is short and scannable (no long paragraphs) | [ ] |
| 8 | Spelling and grammar are clean | [ ] |
| 9 | It is tailored to this post (not copy-paste) | [ ] |
| 10 | A portfolio link or sample is included or offered | [ ] |

**Score: ___ / 10**

- **8 to 10:** send it.
- **5 to 7:** fix the weak lines first (usually the hook or the proof).
- **Below 5:** rewrite using the 5-Line Proposal framework.

> **Tip:** The two lines that most often cost points are the **hook** (too generic) and **proof** (missing).
> Fix those first, they move the needle most.
