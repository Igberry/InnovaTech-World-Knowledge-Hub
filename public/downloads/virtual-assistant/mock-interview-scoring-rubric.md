# Mock Interview Scoring Rubric

> Your mentor scores your mock interview on this. Use it to prepare, and to self-review a recording.
> Score each 1 (weak) to 5 (strong).

| Area | What strong looks like | Score (1-5) |
|---|---|---|
| **Opening** | Clear 30-second intro: niche, who you help, proof | |
| **Fit / "why you"** | Mirrors the client's need; backs it with proof | |
| **Proof & portfolio** | References real samples; shows, not just tells | |
| **Communication** | Clear, warm, concise; good listening | |
| **Tools & process** | Describes a real system for managing work | |
| **Handling the unknown** | Research then ask; no bluffing | |
| **Rate confidence** | States rate calmly; no apologising or caving instantly | |
| **Questions asked** | Asks thoughtful questions about scope and success | |
| **Professionalism** | On time, good setup, tidy background, positive tone | |
| **Close** | Confirms next step; thanks the client | |

**Total: ___ / 50**

- **40+:** interview-ready.
- **30 to 39:** solid; sharpen the lowest two areas.
- **Below 30:** practise the opening, proof, and rate confidence first.

## Top fixes after a mock

- Tighten the opening to 30 seconds.
- Replace vague claims with a specific sample.
- Practise stating your rate once, calmly, then stop talking.

> **Tip:** With permission, record the mock and watch it once. Seeing yourself is the fastest way to improve.
