# VA Career Package Checklist (Final Deliverable)

> Your graduation deliverable is a complete, ready-to-use career package. Tick each item. This is what you
> leave the program with, and keep using.

## The package

- [ ] **Niche Statement** (Week 1), specific and credible
- [ ] **Three live profiles** (Week 2): Upwork, LinkedIn, and a Nigeria-accessible marketplace, all complete
      and consistent with your niche
- [ ] **Portfolio** (Week 4): 2 to 4 case studies (Problem → Action → Result), no private data
- [ ] **Rate sheet** (Week 4): researched rates, Naira and USD
- [ ] **Full Application Tracker log** (Weeks 3 to 6): daily applications with status
- [ ] **Outcome:** either a **signed client/job**, or a **documented next-steps plan** (your 90-day goal)

## Supporting assets you also have

- [ ] Proposal framework + scoring checklist
- [ ] Cold outreach templates
- [ ] Customer-service templates
- [ ] Onboarding checklist + check-in message examples
- [ ] Scam red-flag checklist + rate-negotiation scripts

## Final check

- [ ] Every profile links to the portfolio
- [ ] No real client private data anywhere public
- [ ] Trackers and plans saved in `04-Admin-Invoices/`
- [ ] 90-day goal set and visible to you

> **Remember:** Success is measured by **momentum**, a complete career package and an active pipeline, not
> a guaranteed job on day 49. You finish ready and already applying. Keep going.
