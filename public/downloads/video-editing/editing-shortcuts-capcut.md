# CapCut editing actions: learner reference

CapCut controls differ across phone, desktop, operating system and version. This reference intentionally describes actions rather than fixed keyboard shortcuts. Check the current in-app menus and official help before relying on a key combination.

| Editing goal | Action to find |
|---|---|
| Add footage | Import or add media |
| Place a clip | Drag or insert it on the timeline |
| Shorten a clip | Trim a clip edge |
| Remove a middle section | Split, select the unwanted section, delete, then close the gap if needed |
| Change order | Drag a clip along the timeline |
| Adjust speed | Select a clip and locate speed controls; review the result for smoothness |
| Reframe | Select a clip and adjust crop, scale or position |
| Add a title | Add a text layer, set its duration and check safe margins |
| Add captions | Use an available caption workflow, then proofread every word |
| Mix audio | Adjust clip volume and listen with headphones |
| Export a review copy | Find the current export/share command and verify resolution and destination |
