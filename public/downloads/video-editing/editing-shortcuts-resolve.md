# DaVinci Resolve editing actions: learner reference

Resolve's interface and hardware requirements can change. Use the current Blackmagic Design documentation and the software's menus to confirm each action. The steps below describe goals rather than fixed keyboard shortcuts.

| Editing goal | Area or action to find |
|---|---|
| Sort footage | Media pool or media bins |
| Preview footage | Source viewer |
| Assemble clips | Timeline in the Cut or Edit workspace |
| Shorten a clip | Trim an edge or use a split/edit point |
| Remove a section | Select the section and choose the intended delete behavior |
| Add a title | Titles or graphics controls available in the installed version |
| Adjust colour | Colour workspace; begin with exposure and white balance |
| Check audio | Fairlight or the audio controls available in the installed version |
| Export | Deliver workspace or the current render/export workflow |
