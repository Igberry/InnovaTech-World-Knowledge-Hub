# Week 4 checkpoint: raw-clip set brief

This brief describes a clip set for a timed assessment; no video files are bundled. The facilitator may supply a permitted local clip set, or the learner may film their own safe, consented subject. Do not use footage of strangers or download copyrighted sample footage.

## Suggested clip set

Capture or receive:

1. One establishing wide shot.
2. Three medium process shots with different actions.
3. Three close-up or detail shots.
4. One clean ending shot with space for a title.
5. One short voice line or a provided script for voice-over.
6. A few seconds of room tone.

Use the fictional Fresh Bites brief or another subject you own. The set should contain enough usable material to create a 30-second captioned video; it does not need to be an actual food business.

## Assessment output

- One 30-second edit with a clear title and captions.
- Speech or permitted natural audio that remains intelligible.
- Music only if the facilitator provides an appropriately licensed file; otherwise use no music.
- A short edit note describing the audience, strongest cut and one limitation.

## Facilitator preparation

Prepare a small, locally stored set of permitted clips and a licence/permission note before the session if using supplied footage. Do not ask learners to upload files to a public service.
