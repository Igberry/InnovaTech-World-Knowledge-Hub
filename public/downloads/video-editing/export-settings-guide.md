# Export and delivery guide

Export settings depend on the destination, source footage, editor version, device and current platform requirements. No fixed platform limits are asserted in this guide. Check the current official destination requirements and the editor's export options before producing a client deliverable.

## Choose the purpose first

| Purpose | Starting point |
|---|---|
| Phone-first vertical social video | Confirm the platform's current aspect ratio, dimensions, duration and safe zones; preview captions and controls. |
| YouTube or a landscape presentation | Match the frame to the source and confirm the current upload and playback requirements. |
| WhatsApp-friendly review | Use a smaller, easily playable copy; send a local review first if data is limited. |
| Archive / future re-edit | Keep the editor project, original footage and a high-quality export in the agreed archive. |

## Export checklist

- [ ] Confirm the requested destination and current requirements with the client.
- [ ] Match the timeline frame to the source material where practical.
- [ ] Select a common supported file type offered by the editor; verify it opens on a second device.
- [ ] Watch the exported file from start to end.
- [ ] Check sound, captions, title margins, aspect ratio and picture quality.
- [ ] Check file size against the agreed delivery method and available data.
- [ ] Name the file with project, version and status; mark review copies clearly.
- [ ] Keep the project and original footage until delivery is approved and retention terms are met.

## Currency note

Platform specifications and editor presets change. Official vendor and platform pages could not be reached from the authoring environment on 13 November 2026, so exact limits and preset names are intentionally omitted. Before a live delivery, check the official platform help page and record the date, link and settings used in the project notes.
