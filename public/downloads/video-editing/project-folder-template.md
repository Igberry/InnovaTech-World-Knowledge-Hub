# Video project folder template

Create one copy of this structure for each project. Keep the original camera files unchanged.

```text
PROJECT_NAME/
  01-Raw/          Original footage; do not rename or overwrite originals
  02-Audio/        Voice-over, room tone and licensed sound
  03-Graphics/     Approved logos, titles and graphics
  04-Projects/     Editor project files, versions and edit notes
  05-Exports/      Review copies and approved delivery files
  06-Archive/      Delivery note, licence log and archive checklist
```

## File naming pattern

`YYYY-MM-DD_Project_Content_v01.ext`

Fictional example: `2026-11-13_FreshBites_MenuCloseup_v01.mp4`

Do not put a real person's private information in a file name. Keep a second copy of important work on a separate storage device when possible, and test that the copy opens before deleting anything.
