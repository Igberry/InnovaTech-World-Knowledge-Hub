# Productivity shortcuts cheat sheet

Shortcut availability can depend on the app, operating system, browser and keyboard layout. Use the app's current Help menu or keyboard-shortcut list when a combination behaves differently.

| Task | Common shortcut or method |
|---|---|
| Undo / redo | `Ctrl+Z` / `Ctrl+Y` on Windows and ChromeOS; `Command+Z` / `Command+Shift+Z` on Mac |
| Copy / paste | `Ctrl+C` / `Ctrl+V` on Windows and ChromeOS; `Command+C` / `Command+V` on Mac |
| Find text | `Ctrl+F` on Windows and ChromeOS; `Command+F` on Mac |
| Open a link or insert one | Select text, then use the app's Insert link command; `Ctrl+K` / `Command+K` is common in Docs |
| Find an app command | Use the menus or Help search; don't assume a shortcut exists in every app |
| Navigate Drive | Use the search bar and a consistent folder structure |
| Work on mobile | Use the app's visible controls; desktop keyboard shortcuts may not apply |

Do not treat this as a complete shortcut list. In Docs, Sheets or Slides, open the current keyboard-shortcut help from the app menu and learn only the few commands you use every day.
