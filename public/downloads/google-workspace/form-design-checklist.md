# Google Forms design and privacy checklist

## Before creating the form

- [ ] State the form's purpose in one sentence.
- [ ] Ask only questions needed for that purpose.
- [ ] Do not collect names, phone numbers, addresses, account credentials or other identifying details for the practice exercise.
- [ ] Use fictional questions and responses; do not copy a real customer's feedback.
- [ ] Add a short notice explaining that the answers are fictional course data and how the practice sheet will be used.
- [ ] Decide who needs access to the form and the linked response sheet.

## While building

- [ ] Use a short title and an introductory sentence.
- [ ] Group related questions into sections only when it helps the respondent.
- [ ] Mark only essential questions as required.
- [ ] Use the simplest response type that fits the question.
- [ ] Add validation when it prevents an obvious input error.
- [ ] Preview the form on a narrow phone screen and test every branch.
- [ ] Check the confirmation message and response settings.

## Before sharing

- [ ] Inspect whether the form is restricted to an organisation or open to anyone with the link.
- [ ] Check whether collecting email addresses is enabled; turn it off for the fictional exercise unless explicitly needed.
- [ ] Inspect permissions on the linked response Sheet separately.
- [ ] Submit a test response and remove it before the exercise starts.
- [ ] Share only with the intended practice audience.
- [ ] Stop accepting responses when the exercise ends and remove unnecessary access.
