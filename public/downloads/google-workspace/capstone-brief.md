# Capstone brief: Remote Team Workspace

Design a fictional Google Workspace setup for Fresh Bites, a six-person food business team. This is a practice architecture, not a request to create files in anyone else's account.

## Deliverables

1. A Drive folder structure with access that matches the role matrix.
2. Three reusable Docs or Sheets templates: an order SOP, a weekly report and an order tracker.
3. A fictional Form connected to a response Sheet with a summary dashboard.
4. A shared team calendar with a recurring weekly meeting and a linked agenda.
5. A completed sharing and security audit checklist.
6. A 10-minute walkthrough, live or recorded, using fictional data only.

## Team roles

Use `team-roles-matrix.csv` as a starting point for the owner, cook, counter team, rider, mentor and learner. Give each role only what it needs. In a personal-account exercise, simulate roles with folders and a permission plan; do not create extra accounts or invite real people just to complete the assignment.

## Definition of done

- Every file has a clear name and owner.
- The order tracker has a status and a simple summary.
- The form asks only necessary fictional questions and contains no real personal data.
- The linked Sheet and Form have been checked separately for access.
- Calendar invites go only to a test address controlled by the learner or explicitly approved for training.
- Any plan-dependent feature has an equivalent alternative or is labelled as optional.
- The learner can explain one risk they found and how they reduced it.
- All temporary sharing is removed when the mentor confirms the review is complete.
