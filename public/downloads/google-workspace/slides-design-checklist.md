# Google Slides design and accessibility checklist

- [ ] One main message per slide.
- [ ] Use a short, descriptive title that communicates the point.
- [ ] Keep body text readable from the back of a room; do not shrink text to fit a paragraph.
- [ ] Use strong contrast between text and background; do not rely on colour alone to distinguish series or status.
- [ ] Use consistent type, spacing and alignment.
- [ ] Label charts, units and sources; avoid decorative 3D effects.
- [ ] Add meaningful alternative text to informative images or charts where the editor provides it.
- [ ] Mark purely decorative images appropriately so they do not add noise for screen-reader users.
- [ ] Use a logical reading order and check the outline or screen-reader order.
- [ ] Add speaker notes for context that does not belong on the slide.
- [ ] Use transitions and animations sparingly; do not make motion necessary to understand the message.
- [ ] Test in presentation mode and export a PDF copy for a final visual check.
- [ ] Confirm that any linked spreadsheet or image is visible to the intended audience only.
