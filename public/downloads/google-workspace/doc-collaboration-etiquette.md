# Google Docs collaboration etiquette

Use these practices in the Week 2 comment-and-suggestion exercise.

1. Give the document a clear title and make the owner visible.
2. Share only with the intended practice account. Check whether the recipient needs Viewer, Commenter or Editor access.
3. Use a comment to ask a focused question or explain a requested change. Tag a person only when an action is genuinely theirs.
4. Use Suggesting mode for proposed wording changes that the document owner should accept or reject.
5. Resolve a comment only after the action is complete or the owner agrees it no longer needs attention.
6. Use a named version before a major review. A version history is useful, but it is not a substitute for a separate backup.
7. Keep feedback about the document, not the person. Give a specific reason and a practical next step.
8. Do not paste private customer, student or employment information into a training document.
9. Before publishing a link, inspect its audience and remove practice access when the exercise ends.
10. Read the final document in its exported format; page breaks, links and tables may differ from the editor view.
