# Gmail search operators

These examples follow Google's Gmail Help article, checked 12 November 2026. Search behavior can change; test an operator in your own mailbox before creating a filter. The examples below use fictional content.

| Need | Search |
|---|---|
| Messages from a sender | `from:orders@freshbites.example` |
| Messages to a recipient | `to:training@freshbites.example` |
| Words in a subject | `subject:weekly report` |
| Messages with attachments | `has:attachment` |
| Unread messages | `is:unread` |
| Messages older than 30 days | `older_than:30d` |
| Combine a sender and subject | `from:orders@freshbites.example subject:reservation` |
| Exclude a word | `menu -draft` |

## Practice safely

Search only in your own training mailbox. A search operator does not move or delete a message; a filter may archive, label or otherwise change future mail, so review every filter action before saving. Do not use a real customer's address or message for the exercise.
