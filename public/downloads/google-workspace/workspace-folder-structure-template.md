# Workspace folder structure template

Create these folders in a practice Drive you control. This is a suggested structure, not a permission configuration.

```text
Fresh-Bites-Practice/
├── 00-Read-Me/
├── 01-Inbox-and-Calendar/
├── 02-Docs/
│   ├── SOP/
│   └── Proposals/
├── 03-Sheets/
│   ├── Inventory/
│   └── Sales/
├── 04-Slides/
├── 05-Forms-and-Responses/
├── 06-Site/
├── 07-Meetings/
└── 99-Archive/
```

## Naming pattern

`YYYY-MM-DD_Project_Document_v01`

Examples:

- `2026-11-12_FreshBites_OrderSOP_v01`
- `2026-11-12_FreshBites_SalesTracker_v01`

Use fictional content only. Do not place real customer or student information in this practice folder. Before sharing a folder, inspect the access of the folder and the files inside it.
