# Drive sharing and account security audit

Use this checklist on your own practice files only. Do not audit someone else's account or files without permission.

## File and folder access

- [ ] Identify the owner of the file or folder.
- [ ] List direct people and group access.
- [ ] Check whether link access is Restricted, organisation-only or anyone with the link.
- [ ] Check inherited folder permissions and any exceptions.
- [ ] Confirm that each recipient needs the assigned role: Viewer, Commenter or Editor.
- [ ] Remove test access that is no longer needed.
- [ ] Review sensitive subfolders separately; a broad parent folder can expose child content.
- [ ] Re-open the link in a private test session only if it is your own file and the test does not expose real data.

## Account habits

- [ ] Review account recovery methods and 2-Step Verification.
- [ ] Review recent security activity directly from Google Account settings.
- [ ] Review connected third-party apps and remove anything you do not recognise.
- [ ] Do not approve an unexpected sign-in or OAuth permission request.
- [ ] Do not share passwords, passkeys, one-time codes or recovery codes.
- [ ] Check storage and remove only files you know are safe to delete.
