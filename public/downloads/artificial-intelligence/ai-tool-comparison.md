# AI Tool Comparison Worksheet

> Tools, prices and free tiers change fast. This worksheet helps you compare tools by category
> and decide what to use, instead of memorising brand names. Verify current details on each
> tool's own website before you rely on it. Fill in the blanks yourself.

## 1. What am I trying to do?

Write your task first. The task decides the tool, not the other way round.

- My task: _______________________________________________

## 2. Tool categories (what each is for)

| Category | What it does | What to check before using |
|---|---|---|
| Chat / text assistant | Answer questions, write, summarise, explain | Free tier limits; can it browse the web; data/privacy policy |
| Image generator | Create or edit images from a description | Cost; usage/commercial rights; content rules |
| Writing helper | Draft and edit documents and emails | Free tier; where your text is stored |
| Transcription | Turn speech/audio into text | Accuracy; language support; privacy |
| Translation | Translate between languages | Accuracy for your languages; privacy |
| Coding helper | Explain or write small code snippets | Whether output is correct; licence of code |
| Search / research | Find and summarise information with sources | Does it cite sources you can check |

## 4. Questions to answer for each tool

- [ ] Is there a genuinely free tier, and what are its limits?
- [ ] How much data does it use? Can I use it on a low-data plan?
- [ ] What happens to what I type? Is it stored or used for training?
- [ ] Does it give sources I can verify?
- [ ] Are there rules on how I can use the output (especially images)?

> **Note:** You do not need many tools. One good chat assistant and one image tool cover most
