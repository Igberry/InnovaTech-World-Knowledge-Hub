# Remote-readiness checklist

Work through this over the 6 weeks. By the end, every box should be ticked.

## Setup & reliability
- [ ] A quiet, tidy spot to take video calls
- [ ] A backup plan for power (charged power bank / knows nearest reliable spot)
- [ ] A backup plan for internet (second SIM / data bundle / known hotspot)
- [ ] A professional email address
- [ ] A device that can run video calls

## Brand
- [ ] One-page CV (PDF), tailored per application
- [ ] Complete LinkedIn profile (see the LinkedIn checklist)
- [ ] A portfolio or proof-of-work link
- [ ] 1-3 references or recommendations (with permission)

## Finding work
- [ ] A list of 2-3 job boards / platforms for your field
- [ ] An application tracker in use
- [ ] Outreach templates saved and personalised per send
- [ ] You can spot and avoid common scams

## Skills
- [ ] Comfortable with written, async communication
- [ ] Familiar with common tools (chat, video, a task board, shared docs)
- [ ] Can manage your time and time-zone overlap
- [ ] Reliable: you reply, show up, and meet deadlines

## Getting hired & paid
- [ ] Practised common interview questions (see the question bank)
- [ ] Understand how you'll get paid internationally (check current options)
- [ ] Know how to agree scope, hours and rate in writing
