# Fresh Bites office standards

**Fictional practice guide — adapt only with an authorised organisation's approval**

## Files and folders

- Keep work in the approved project folder and use the shared folder structure.
- Preserve original inputs and create a working copy before editing.
- Name files `YYYY-MM-DD_Client_Document_v01.ext`; increase the version when a substantial revision is made.
- Use the correct extension and app. Export an approved PDF when a read-only copy is needed.

## Documents and spreadsheets

- Use Word heading styles, readable tables and consistent spacing.
- Keep Excel data in one header row with one record per row; do not mix totals into the data.
- Label units, assumptions, fictional examples and source dates.
- Use PowerPoint layouts and master styles so the deck remains consistent.

## Email and meetings

- Use a descriptive subject and a concise, respectful message.
- Check recipients before sending; use Reply All only when everyone needs the response.
- Attach a file only when necessary; use an approved, permission-limited link for shared files.
- State the time zone in invitations and record decisions and owners in meeting notes.

## Sharing and security

- Share only with authorised people and grant the least access needed.
- Do not share passwords or verification codes.
- Check permissions, document comments, tracked changes and metadata before external sharing.
- Report unexpected sign-in requests, suspicious links and lost devices through the approved process.
