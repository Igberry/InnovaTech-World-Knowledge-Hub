# Windows and Office keyboard shortcuts

Shortcuts below are common on Windows keyboards. Laptop layouts, accessibility settings, web apps and software versions can change how a shortcut behaves. Search the ribbon with **Alt+Q** when you cannot find a command.

## Windows and File Explorer

| Shortcut | Common action |
|---|---|
| `Win+E` | Open File Explorer |
| `Win+S` | Open Windows search |
| `Alt+Tab` | Switch between open apps |
| `F2` | Rename the selected file or folder |
| `Ctrl+C` / `Ctrl+X` / `Ctrl+V` | Copy / cut / paste |
| `Ctrl+Z` | Undo the last action where supported |
| `Ctrl+A` | Select all items in the active area |
| `Shift+Delete` | Permanently delete in some Windows contexts; avoid during practice |
| `Alt+Enter` | Open properties for a selected item |

## Word, Excel and PowerPoint

| Shortcut | Common action |
|---|---|
| `Ctrl+S` | Save |
| `Ctrl+P` | Print or open print preview |
| `Ctrl+F` | Find |
| `Ctrl+H` | Find and replace in many Office desktop apps |
| `Ctrl+B` / `Ctrl+I` / `Ctrl+U` | Bold / italic / underline |
| `Ctrl+Z` / `Ctrl+Y` | Undo / redo |
| `Ctrl+K` | Insert or edit a hyperlink |
| `Alt+Q` | Search for a command in supported Office versions |
| `F5` | Start a PowerPoint slide show from the beginning in many desktop versions |

In Excel, `Ctrl+Arrow` moves toward the edge of a data region; `Ctrl+Shift+Arrow` selects to that edge. Confirm the selected range before formatting or deleting. `Ctrl+1` opens cell formatting in many desktop versions.

## Safe use

Save before making a broad change. If a shortcut opens something unexpected, press `Esc` or use `Ctrl+Z` only after checking what changed. Do not use permanent-delete shortcuts on real files. For a screen reader or other assistive technology, consult the official shortcut list for the specific app and version you use.
