# Work folder structure template

Create this structure for the fictional Yenagoa Fresh Bites practice case. Keep one copy of each original starter in `00_Inbox_Originals`; work on copies in the appropriate folder.

```text
FreshBites_Practice/
├── 00_Inbox_Originals/
├── 01_Admin/
│   ├── Letters/
│   ├── Meetings/
│   └── Office_Standards/
├── 02_Customers/
│   └── Mail_Merge_Practice/
├── 03_Finance/
│   ├── Budgets/
│   └── Sales/
├── 04_Inventory/
├── 05_Marketing/
│   ├── Flyers/
│   └── Presentations/
├── 06_Proposals/
├── 07_Exports/
│   ├── PDF/
│   └── Screenshots/
└── 99_Archive/
```

## Folder rules

- Put editable Word files in the closest matching work folder; put final sharing copies in `07_Exports`.
- Preserve an untouched starter in `00_Inbox_Originals` and work from a duplicate.
- Use a clear date-first file name such as `2026-11-12_FreshBites_SupplierLetter_v01.docx`.
- Increase the version number when a substantial revision is made; do not overwrite a file another person is reviewing.
- Use `99_Archive` for old drafts only after checking that no shared process still depends on them.
- Keep personal, student, client and payment records out of this fictional course folder.
