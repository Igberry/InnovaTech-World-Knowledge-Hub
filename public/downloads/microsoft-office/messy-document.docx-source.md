# Week 2: deliberately inconsistent Word practice text

This is fictional text for rebuilding as a clean one-page document. Copy the text into Word; it is not a ready-made document or a model answer. The inconsistent headings, spacing and table text are intentional. Do not use this practice copy as a real quotation or supplier order.

## Rebuild task

Use the supplied text to create a fictional business letter. Add a clear title, set a consistent body style, format the list of items as a real Word table, use readable paragraph spacing, and check the page in Print Preview. Use a neutral placeholder instead of invented contact details. If you display the sample amounts, retain the note that they are fictional practice data.
