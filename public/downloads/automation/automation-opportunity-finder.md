# Automation Opportunity Finder

> Automation is best used on tasks that are repetitive and follow clear rules. This worksheet helps
> you find the right tasks to automate, and spot the ones you should leave to a human.
> Replace the sample rows with your own.

## 1. List your repeating tasks

Write down tasks you (or a business you know) do again and again. Use the task-audit log to track them
over a week if you are not sure.

| Task | How often | Roughly how long each time |
|---|---|---|
| Example: Reply "we received your message" to new enquiries | Many times a day | 2 min |
| Example: Copy new sign-ups into a spreadsheet | Daily | 10 min |

## 2. Score each task

For each task, score 1 (low) to 5 (high):

| Task | Repetitive? | Rule-based? | Time it takes | Worth automating? (total) |
|---|---|---|---|---|
| | | | | |
| | | | | |

- **Repetitive:** does it happen often?
- **Rule-based:** are the steps the same each time, with clear decisions?
- **Time:** does it eat real time (per task x how often)?

The tasks that score high on all three are your best automation candidates.

## 3. What NOT to automate (leave to a human)

Be honest about these. Do not automate:

- [ ] Tasks that need **judgement** or **empathy** (handling an upset customer, a sensitive decision)
- [ ] Tasks where a **mistake is costly** and hard to undo (sending money, deleting records)
- [ ] Tasks that **change every time** (no clear rule)
- [ ] Anything that would **break a platform's rules**, spam people, or deceive

> **Rule of thumb:** Automate the boring, repetitive, rule-based parts. Keep the judgement, the
> relationships, and the risky final decisions with a human.
