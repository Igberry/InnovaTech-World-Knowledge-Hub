# Trigger-Action Planner

> Most automations follow one shape: "WHEN something happens (trigger), DO something (action)."
> Use this to plan one automation before you build it. Replace every [bracket].

## The task this automates

- Task: _______________________
- How often it happens now: _______________________
- Who does it now: _______________________

## The trigger (WHEN...)

What event starts the automation?

- Trigger: When [a new form is submitted / a new email arrives with X / a row is added / a time is reached]
- Where the trigger comes from (which app/tool): _______________________

## The action (DO...)

What should happen automatically?

- Action: [send a reply / add a row to a spreadsheet / create a task / send a notification]
- Where the action happens (which app/tool): _______________________

## Any conditions (ONLY IF...)

Should it only run in some cases? Keep it simple.

- Only run if: [e.g., the email is from outside the company / the amount is over N5,000]
- Otherwise: [do nothing / do something else]

## What could go wrong

- If the trigger fires by mistake, the worst that happens is: _______________________
- How I will know if it fails: _______________________
- How I would undo it: _______________________

## Test plan (before it touches anything real)

- [ ] I will test with sample data, not real customers
- [ ] I will run it once and check the result by hand
- [ ] I will watch it for a few real runs before trusting it

> **Warning:** Never point a brand-new automation at real customers, real money, or the only copy of
> important data. Test on a safe copy first.

> **Tip:** One trigger, one action, one condition is plenty for your first automations. You can add more
> steps once the simple version works reliably.
