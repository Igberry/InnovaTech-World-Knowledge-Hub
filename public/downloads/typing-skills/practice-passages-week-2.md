# Week 2 Practice Passages

All passages are original and fictional. Type each once slowly, then repeat at a comfortable pace. Record only results you actually measured.

## Passage 1: Short words

The red bag is on the desk. A small note is beside it. Read the note, then ask for help if a word is not clear. Slow hands can make clean work. A calm pace is better than a rushed mistake.

## Passage 2: At the counter

The team checks each order before it leaves the counter. One person reads the list, another checks the items, and a third marks the order ready. If a name or time is unclear, the team asks rather than guessing.

## Passage 3: A practice plan

Set a short goal for today. Practise a few keys, pause, and return to the home row. If a letter feels awkward, type it slowly in a few words. Keep your shoulders relaxed and write one note about what improved.

## Passage 4: A clear message

Hello, I have received your order for two meals and one drink. Please confirm the collection time before we prepare it. Thank you for checking the details with us.

## Passage 5: Review the record

On Thursday, the team reviewed its practice list. The first copy had a missing word and an extra space. The second copy was easier to read because the writer used short sentences, checked punctuation, and paused before sending it. Good work is clear, complete, and checked by the person who prepared it.
