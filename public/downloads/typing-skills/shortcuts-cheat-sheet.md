# Keyboard Shortcuts Cheat Sheet

Shortcuts can vary by operating system, keyboard layout and application. Test a shortcut in a blank document first.

| Task | Windows (common) | macOS (common) |
|---|---|---|
| Copy / cut / paste | Ctrl+C / Ctrl+X / Ctrl+V | Command+C / Command+X / Command+V |
| Undo / redo | Ctrl+Z / Ctrl+Y | Command+Z / often Shift+Command+Z |
| Select all | Ctrl+A | Command+A |
| Save / print / find | Ctrl+S / Ctrl+P / Ctrl+F | Command+S / Command+P / Command+F |
| Bold / italic / underline | Ctrl+B / Ctrl+I / Ctrl+U | Command+B / Command+I / Command+U |
| Delete previous word | Ctrl+Backspace | Option+Delete in many apps |
| Move by word | Ctrl+Left/Right Arrow | Option+Left/Right Arrow in many apps |
| Select text | Shift+Arrow; Ctrl+Shift+Arrow for words | Shift+Arrow; Option+Shift+Arrow for words |
| Switch apps | Alt+Tab | Command+Tab |
| Move to line start/end | Home/End in many apps | Command+Left/Right in many apps |

Windows-key shortcuts depend on Windows version. Use the application's own Help or official support page when a combination differs. Undo is useful, but save before making risky changes.
